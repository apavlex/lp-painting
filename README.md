# LP Painting

Marketing site for **LP Painting** — interior & exterior painting and pressure washing across Washington & Oregon.

Built from the [Google Stitch](https://stitch.withgoogle.com/) design **LP Painting - Home & Free Estimate**.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Local development server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build |
